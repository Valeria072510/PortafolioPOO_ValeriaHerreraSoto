# 1. ¿Qué contiene el portafolio?
Este portafolio de evidencias recopila los proyectos y módulos prácticos desarrollados a lo largo del periodo académico en la materia de Programación Orientada a Objetos. Contiene soluciones de software modulares que avanzan desde la lógica de escritorio hasta la arquitectura web, organizadas de la siguiente manera:

Módulo de Gestión de Acceso de Usuarios (Consola - Python): Una solución modular orientada a objetos que implementa un menú interactivo para el registro y categorización de perfiles con control de permisos dinámicos y validación estricta de credenciales.

Módulo de Gestión Estadístico de Inventario (Web - PHP): Una aplicación basada en la captura masiva de datos que implementa la lógica de arreglos paralelos unidimensionales para procesar variables financieras y devolver reportes métricos de forma automatizada.

Módulo de Gestión de Bitácoras Diarias en Archivos de Texto (Web - PHP): Un prototipo digital ligero diseñado para la persistencia de datos local, enfocado en el manejo de flujos de entrada y salida de datos (I/O) utilizando ficheros planos para el control de incidentes sin dependencia de bases de datos.

 # 2. ¿Qué tecnologías se utilizaron?
Para el desarrollo de los proyectos integrados en este portafolio, se empleó un conjunto de tecnologías de software estándar en la industria:
Python 3.x: Utilizado como el lenguaje base para la implementación de estructuras de datos y lógica pura de Programación Orientada a Objetos en entornos de consola.
PHP 8.x: Empleado como el lenguaje de programación del lado del servidor (Backend) para la gestión de peticiones HTTP, procesamiento analítico de arreglos y manipulación del sistema de archivos locales.
HTML5 & CSS3: Tecnologías del lado del cliente (Frontend) aplicadas para estructurar formularios interactivos de captura de datos y renderizar interfaces limpias, visuales y adaptativas para el usuario.
Servidor Web Apache (XAMPP): Entorno de desarrollo local utilizado para interpretar el código PHP y simular el comportamiento real de una infraestructura de red de servidor a cliente.
Expresiones Regulares (RegEx): Herramienta de coincidencia de patrones utilizada para la validación y sanitización avanzada de cadenas de texto (como la validación de correos electrónicos).

# 3. ¿Qué competencias se desarrollaron?
A través de la resolución práctica de estas actividades orientadas a problemas reales, se consolidaron las siguientes competencias profesionales y técnicas:
Dominio del Paradigma de la POO: Capacidad de modelar entidades del mundo real en clases y objetos, aplicando de forma efectiva la abstracción, el encapsulamiento para la protección de datos, la herencia para la reutilización de código y el polimorfismo para estructurar comportamientos flexibles y dinámicos.
Desarrollo de Lógica Web Backend: Habilidad para interceptar y gestionar transferencias de datos asíncronas a través de métodos de petición HTTP (POST), vinculando exitosamente los formularios de la interfaz con los scripts de procesamiento en el servidor.
Manipulación Segura de Archivos y Persistencia: Competencia para leer y escribir de forma incremental en flujos de datos físicos, aplicando mecanismos de control de concurrencia (bloqueos exclusivos con LOCK_EX) y formateo nativo de archivos planos.
Sanitización de Datos y Mitigación de Vulnerabilidades: Capacidad para validar y limpiar las entradas del usuario en el Backend (mediante funciones como htmlspecialchars), previniendo errores de ejecución, corrupción de registros o ataques comunes de inyección de código como Cross-Site Scripting (XSS).
Modularidad y Clean Code: Conciencia técnica para separar el código en capas o archivos independientes, mejorando la escalabilidad, la legibilidad y facilitando el mantenimiento a largo plazo del software desarrollado.
